# 杯柜清场（Cup Shelf Clear）产品需求文档

| 字段 | 内容 |
|------|------|
| 版本 | 1.0 |
| 日期 | 2026-11-06 |
| 平台 | 微信小游戏（当前交付为可测核心 + 浏览器预览） |
| 一局时长 | 约 8–15 分钟（长局） |

## 1. 定位

**一句话**：在杂乱饮品柜里，通过点选三同消除、轻量挪位（华容道感）、道具解困，把整柜清空。

对标手感：微信小游戏里「找东西 / 收纳整理 / 轻华容道 + 道具救场」的长局，而不是 60 秒短平快三消。

主题：奶茶 / 咖啡等饮品（美术阶段可用色块 + emoji / 文字占位）。

## 2. 核心循环

1. 观察多层货架上**露出的顶杯**（下层被遮挡，形成找物感）。
2. 点选可操作顶杯，进入底部**出杯槽**。
3. 槽内任意 **3 个相同**饮品立即消除并腾位。
4. 必要时用**同行相邻空位滑动**挪开堵路杯子，或使用道具。
5. 清空货架与出杯槽 → 通关；槽满且无法三消 → 失败（可用道具救场）。

## 3. 规则细则

### 3.1 货架与遮挡

- 货架建议 **4–6 行**，每格可叠多层杯子。
- 仅可操作该格**栈顶（露出）**杯子。
- 冰块顶杯不可点，需冰锥或「相邻取走触发震碎」。
- 锁定顶杯不可点，需钥匙道具或激励视频解锁（广告接口占位）。

### 3.2 出杯槽

- 默认容量 **7**，道具「扩槽」可 +1，**上限 8**。
- 点杯入槽；槽内同款达 3 立即消除（可连锁结算到无法再消）。
- 槽满且结算后仍无法消除 → 本局失败。

### 3.3 轻量挪位（华容道感）

- 同一行内，露出的非冰非锁杯子可滑入**相邻空格**（一次一格）。
- 每局有 **moveQuota** 次数限制。
- 用途：露出被挡的同款、整理通路，而不是完整华容道推箱子。

### 3.4 障碍

| 障碍 | 行为 | 解除 |
|------|------|------|
| 冰块 | 顶杯不可点选 | 冰锥道具；或相邻格子发生取杯后震碎 |
| 锁定 | 顶杯不可点选 | 钥匙道具；或激励视频占位 `AdService.showRewarded` |

### 3.5 道具

| 道具 | 效果 |
|------|------|
| 撤销 | 恢复上一步（含货架/槽/配额快照） |
| 磁铁 | 指定种类，最多抽出 2 个露出的该种类入槽并尝试消除 |
| 扩槽 | 出杯槽 +1，上限 8 |
| 重排 | 打乱未结冰、未锁定杯子的排布 |
| 冰锥 | 解除指定顶杯冰块 |
| 钥匙 | 解除指定顶杯锁定 |

关卡 JSON 的 `items` 字段配置初始次数。

### 3.6 胜负与星级

- **胜利**：货架与出杯槽均清空。
- **失败**：出杯槽满且无法三消。
- **星级（粗分）**：通关至少 1 星；终局槽压力低、挪位剩余多、道具消耗少可到 2–3 星。

### 3.7 关卡体量

- 一局 = 一整柜大关，目标 **约 90–120 杯**（教学关可更短）。
- 任意关卡：总杯数及每种饮品数量均须能被 **3** 整除。

## 4. 关卡规划（v1）

| ID | 名称 | 规模 | 说明 |
|----|------|------|------|
| level_01 | 新手柜 · 开业第一天 | 18 杯 | 教学：每格三同，快速理解槽与消除 |
| level_02 | 午后高峰柜 | ~96 杯 | 标准长局，少量冰/锁 |
| level_03 | 深夜清场挑战 | ~120 杯 | 高压长局，障碍更多 |

## 5. 变现点（接口先行）

1. **激励视频**：锁定杯解锁、失败复活（加一次撤销/扩槽）、补发道具。
2. **插屏**：大关结算后（需控制频率）。
3. **道具商城 / 体力**：后续版本；本仓库只保留 `AdService` 占位。

开发期 `showRewarded` 可直接返回 `true`。

## 6. 范围外（本版本不做）

- 正式微信登录、排行榜、社交分享裂变
- 完整 Cocos 场景与正式美术 / 音效
- 联机、赛季通行证、复杂剧情
- 真实广告 SDK 接入（仅占位）

## 7. 验收标准

1. `npm test` 全绿：三同、槽满失败、遮挡/冰锁、挪位、道具、关卡完整性、至少一关可求解通关。
2. 浏览器打开 `preview/index.html`（先 `npm run build:preview`）可玩完 level_01。
3. 文档：`docs/PRD.md`、`docs/TECH.md`、`README.md` 齐全。
4. 仓库不再以旧「饮品消消」Cocos 原型为主体。

## 8. 后续接微信 / Cocos

1. 保持 `src/core` 纯逻辑，Cocos 只做渲染与输入适配。
2. 微信小游戏：用 Cocos 构建微信工程，替换 `AdService` 为 `wx.createRewardedVideoAd`。
3. 美术：替换 emoji/色块为 Sprite；关卡 JSON 格式可继续沿用。
